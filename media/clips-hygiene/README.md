# Clips für das Hygiene-Reel – hier hochladen

Sobald hier echte Videoclips liegen, baut die Wochenauswertung (freitags) daraus mit OpenMontage das Hygiene-Reel: nur deine echten Clips, Text-Einblendungen, Untertitel. Danach wandern die Clips nach `verwendet/`.

## So drehen
- Handy **hochkant**, ruhig halten (abstützen), gutes Licht, kein Gesicht nötig, nur Hände
- Keine Patienten im Bild, keine Patientendaten (Karteikarten, Bildschirme) sichtbar
- Je Clip 3–5 Sekunden, ohne Musik

## Shotlist (Dateinamen bitte so, dann stimmt die Reihenfolge)
1. `01_ablegen.mp4` – benutztes Instrument wird nach der Behandlung abgelegt
2. `02_reinigen.mp4` – Reinigung bzw. Desinfektion
3. `03_verpacken.mp4` – Instrument wird eingeschweißt bzw. verpackt
4. `04_sterilisator.mp4` – Sterilisator wird geschlossen bzw. läuft
5. `05_oeffnen.mp4` – steril verpacktes Instrument wird am Behandlungsplatz geöffnet

Wichtig: Die Schritte müssen genau eurem tatsächlichen Ablauf entsprechen. Fehlt ein Schritt oder ist er anders, einfach weglassen bzw. so drehen, wie es wirklich ist.

## So hochladen (vom Handy)
- Am einfachsten: Clips hier im Claude-Chat anhängen, ich lege sie in diesen Ordner.
- Oder: github.com/BadCorp86/podologie-social → Ordner `media/clips-hygiene` → „Add file“ → „Upload files“ → Clips auswählen → „Commit changes“. Ein Clip darf höchstens 25 MB groß sein, sonst lieber im Chat anhängen.
